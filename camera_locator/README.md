# Camera Locator 模块说明文档

该模块主要用于相机标定辅助，提供了一套基于 PyQt5 的 GUI 工具和底层数据结构，允许用户在相机画面和 2D 小地图上分别选点，从而计算透视变换矩阵或验证 PnP 解算结果。

---

## 1. 文件概览

| 文件名 | 类型 | 主要功能 |
| :--- | :--- | :--- |
| **calib.py** | **GUI 应用** | 一个完整的标定工具界面。左侧显示相机画面，右侧显示比赛场地小地图。用户通过点击对应点对，计算坐标映射关系。 |
| **anchor.py** | **数据结构** | 定义了 `Anchor` 类，用于存储和管理选取的关键点（锚点），支持栈式操作（添加、撤销）。 |
| **point_picker.py** | **基础工具** | 基于 OpenCV 的底层选点交互逻辑。实现了图像缩放、移动和鼠标点击回调，用于精确获取像素坐标。 |

---

## 2. 核心功能详解

### 2.1 交互式标定 (calib.py)
这是一个功能丰富的 PyQt5 应用程序，旨在解决手动标定的痛点：
- **双视图交互**：
  - **左窗口**：显示实时或抓取的相机画面。
  - **右窗口**：显示比赛场地俯视图（小地图，区分红/蓝方）。
- **点对采集**：用户需在左图和右图中依次点击对应的地标点（如高地角点、标柱底座）。
- **多层高标定**：支持“切换高度”功能，允许用户针对不同高度平面（例如地面 0m，高地 0.6m）分别采集点对。
- **数据导出**：支持将标定结果保存为 `.npy` 文件供后续程序调用。

### 2.2 点位管理 (anchor.py)
- **Anchor 类**：
  - 作为一个固定容量（5个点）的容器。
  - 提供 `append` (加点)、`pop` (撤销)、`clear` (清空) 接口。
  - 主要用于在 OpenCV 循环中临时存储用户点击的点位。
- **set_by_hand 函数**：
  - 封装了调用 `PointsPicker` 进行手动选点的流程，直到选满 5 个点为止。

### 2.3 图像选点器 (point_picker.py)
- **PointsPicker 类**：
  - 实现了复杂的鼠标交互逻辑。
    - **左键**：选点，记录坐标。
    - **右键**：拖拽平移图像。
    - **滚轮**：缩放图像（以鼠标为中心）。
  - 支持在高分辨率图像上进行亚像素级的精细选点。

## 3. 使用方法

### 启动标定工具
直接运行 `calib.py`（需要图形化界面支持）：
```bash
python camera_locator/calib.py
```
*(注意：代码中硬编码了配置文件路径和图片路径，运行前请检查 `binocular_camera_cfg_path` 和 `map_red.jpg` 等路径是否正确)*

### 操作流程
1.  程序启动后，左侧显示相机画面，右侧显示小地图。
2.  **点击“开始标定”**。
3.  在**左侧相机画面**中找到一个特征明显的角点，点击选中。
4.  在**右侧小地图**中找到该角点在世界坐标系下的对应位置，点击选中。
5.  重复上述步骤，通常需要选取 4 个以上的对应点对。
6.  如果涉及到不同高度的平面（如高地），点击**“切换高度”**并重复选点。
7.  点击**“保存计算”**，程序将计算对应的变换矩阵并保存到本地文件。

## 4. 接口说明

### Anchor 类
```python
anchor = Anchor()
anchor.append([x, y]) # 添加点
last_point = anchor.pop() # 撤销上一个点
points = anchor[:] # 获取所有点
```

### PointsPicker 类
通常不直接调用，而是通过 `anchor.set_by_hand(image, anchor_obj)` 间接使用。
