空口帧结构

每个发射数据包在空口的结构如下：




空口帧结构表：


字段            长度             值/说明


                             信息波：0x2F6F4C74B914492E，干扰波：0x16E8D377151C712D
Access Code   8 字节(64bits)
                             （大端序）。


                             包含两份相同的 Payload Length（各 16 bits，大端序，值为 15
Header        4 字节(32bits)
                             即 0x000F）。接收端校验两份是否一致，不一致则丢包。


Payload       15 字节          有效载荷数据。


注：红蓝双方使用相同的 Access Code。即红方和蓝方的信息波均使用 0x2F6F4C74B914492E，红方和
蓝方的干扰波均使用 0x16E8D377151C712D。

发送的数据流按 15 字节为一组进行切片，每组作为一个空口包的 Payload，加上 Access Code 和 Header

调制链路补充说明：


 项目                      说明


 前导码(Preamble)           无独立前导码，帧以 Access Code 直接起始


 包间隔                     无固定包间隔，数据到达即发射


 高斯滤波器截断长度               默认 4 个符号周期(GNURadio digital_gfsk_mod 默认值)


 数据白化(Whitening)         无


 前向纠错（FEC）               无

 特征                                           值


 每 bit 持续时间                                   47μs

 bit=1 瞬时频偏                                   +248,723Hz



 bit=0 瞬时频偏                                   -248,723Hz

数据帧协议

数据推送速率：


 波源              推送速率              数据内容


 信息波             1400byte/s        全部为有效数据 0X0A01-0X0A05(10Hz)


 干扰波             1350byte/s        包含 0x0A06 数据（10Hz），其余字节为随机填充
